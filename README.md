# ddtrace-llm-observability-multimodal
Skill reutilizable para implementar y solucionar Datadog LLM Observability con ddtrace en aplicaciones Python, incluyendo instrumentación de spans LLM, trazabilidad multimodal de imágenes y audio, prevención de payloads truncados y errores DATA_ISSUE, sanitización de secretos y URLs, validación de salidas estructuradas y pruebas automatizadas.
